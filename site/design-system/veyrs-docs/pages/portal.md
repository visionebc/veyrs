# Docs Center portal — overrides to MASTER.md

These rules override `../MASTER.md` (generated by UI UX Pro Max with
`--design-system -p "VEYRS Docs" --density 6 --variance 3 --motion 2` for the
query "cybersecurity B2B SaaS technical documentation portal developer docs").
Kept from MASTER: the style (**Minimalism & Swiss Style**, the skill's pick for
documentation sites), light as the default theme, subtle motion only (150–250 ms
hover/colour transitions, no scroll reveals), the 4/8 px spacing scale,
visible focus, reduced-motion support, the 375/768/1024/1440 breakpoints, SVG
icons (never emoji), and the pre-delivery checklist.

Implementation: `site/static/veyrs.css` (tokens + components),
`site/static/theme.js`, `site/static/veyrs.js`, chrome in `site/build.py`.

## Deviations and why

| MASTER says | The portal does | Why |
|---|---|---|
| Primary `#2563EB` (generic trust blue), secondary `#3B82F6` | Primary `#0064D8` (VEYRS brand blue, 5.5:1 on white); dark theme `#5AA9FF` (7.4:1 on `#0B1220`) | Brand continuity with the console, the product site and BRAND.md. The test suite also refuses `#3B82F6`/`#8B5CF6` (the old placeholder gradient). |
| Accent/CTA orange `#EA580C` | No orange CTA. The one primary action per page (Search, Console) uses the brand blue | A documentation portal has no conversion CTA; orange would compete with the status and warning colours. |
| Pattern "Hero + Features + CTA" | Home = documentation dashboard: title, search, figures, task shortcuts, domains, verification status, coverage | The pattern is a landing-page pattern; the skill's own style row lists documentation sites, which need navigation first. |
| Plus Jakarta Sans from the Google Fonts CDN | Inter (UI, body) + JetBrains Mono (code), **self-hosted** woff2, copied at build time from `frontend/console/fonts/` into `/static/fonts/` | The skill's typography search for "documentation technical readable" returned *Minimal Swiss* (Inter) and *Developer Mono* (JetBrains Mono). Self-hosting: no third-party request from an internal docs site, same files as the console (`frontend/console/fonts/`). |
| "Dark mode supported, but avoid for this product"; anti-pattern "dark mode by default" | Light by default (system preference respected), a designed dark theme with its own tokens, toggle in the top bar | The owner asked for light **and** dark. Dark is never forced: `theme.js` follows `prefers-color-scheme` unless the reader chooses. |
| GSAP scroll reveal (motion dial 2) | No animation library, no scroll reveal | Zero third-party code in the docs build (docs/SECURITY.md, build toolchain); content must be visible without JavaScript. |
| Card background `#FAFAFA` | Surfaces are `#FFFFFF` / `#F8FAFC` with hairline borders; the domain grid is one ruled grid, not separate cards | Swiss: grid lines instead of floating cards; avoids the "too many cards" anti-pattern the owner named. |

Status badges carry their word as text (colour is never the only signal):
Verified, Implemented, Partial, Planned, Obsolete, Unknown.

Diagrams are rendered by Mermaid on white and shown on a white card in both
themes (a dark re-render would double the SVGs and their review cost).

## Pre-delivery checklist (run 2026-11-17)

- [x] No emoji icons — inline SVG (Lucide-style strokes), `aria-hidden` when beside text; icon-only buttons have `aria-label`.
- [x] `cursor: pointer` on buttons, summaries and links.
- [x] Hover transitions 150 ms; `prefers-reduced-motion` disables all transitions.
- [x] Text contrast ≥ 4.5:1 in both themes (table above).
- [x] Visible focus: 3 px ring on every interactive element, skip link to `#main`.
- [x] Responsive at 375 / 768 / 1024 / 1440: sidebar becomes an off-canvas drawer below 1024 px (Escape closes it), the right-hand table of contents folds into an "On this page" disclosure below 1280 px, tables scroll inside their own wrapper, no page-level horizontal scroll.
- [x] Breadcrumbs on every document; current page marked `aria-current="page"` in the sidebar.
- [x] Search reachable from every page (top bar, `/` shortcut).
