# frontend

The web console, served as static files by nginx:

- `console/` — `index.html`, `app.js` (vanilla JavaScript, no build step) and `console.css`.
- `brand/` — `veyrs-tokens.css` (design tokens) and `logo/` (logo, mark and favicon assets; see `logo/README.md`).

There is no bundler or package manager; edit the files directly. See `docs/ARCHITECTURE.md`.
