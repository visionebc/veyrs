# Inconsistencies register

Each row names the two statements that disagree, the evidence (repository path and line, at release 0.39.1, `ab8103e`) and the resolution:

- **Fixed in docs**: the document now matches the code.
- **Needs code change**: the code, a code comment, a shipped configuration file or a script message is wrong. It was reported, not changed, because code changes need the owner's approval.
- **Owner decision**: both readings are defensible and the owner has to choose.

The code is the reference. Where two documents disagreed, both were aligned to the code. IDs are stable so other pages can cite them.
